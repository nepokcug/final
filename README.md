## Описание проекта

Веб-сервер на Go с SQLite для управления задачами (TODO-LIST).
Позволяет создавать, редактировать, удалять задачи, а также
отслеживать их выполнение по правилам повторения.

- Регистрация задачи
- Список задач клиента
- Изменение статуса задачи
- Изменение адреса доставки
- Удаление задачи
- JWT-аутентификация
- Поиск задач по названию и дате

## Запуск локально

### 1. Установить зависимости

```bash
go mod download
```

### 2. Запуск сервиса без пароля

```bash
go run main.go
```

Для доступа в браузере: **http://localhost:7540/**

## Запуск всех тестов

### 1. Запустить сервер с паролем

**В отдельном терминале:**

```bash
TODO_PASSWORD="secret123" go run main.go
```

Сервер должен быть запущен во время выполнения тестов.

### 2. Получить JWT-токен

**В другом терминале:**

```bash
curl -X POST http://localhost:7540/api/signin \
    -H "Content-Type: application/json" \
    -d '{"password": "secret123"}'
```

**Ответ:**

```json
{"token": "eyJhbGciOiJIUzI1NiIs..."}
```

### 3. Вставить токен в `tests/settings.go`

```go
var Token = `eyJhbGciOiJIUzI1NiIs...`
```

**Важно:** токен живёт 8 часов. Если истёк — получите новый (шаг 2).

### 4. Запустить тесты

```bash
go test ./tests
```

## Сборка и запуск через Docker

### 1. Собрать образ

```bash
docker build -t my-tracker:v1 .
```

### 2. Запустить контейнер

```bash
docker run -d --name tracker \
    -p 7540:7540 \
    -v "$(pwd)/scheduler.db:/app/scheduler.db" \
    my-tracker:v1
```

### 3. Проверить

```bash
docker ps
```

### 4. Открыть в браузере

**http://localhost:7540/**
